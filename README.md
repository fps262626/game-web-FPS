# CYBER FPS ARENA (game-web-FPS)

ブラウザで瞬時に動作する近未来サイバーFPSシューティングゲーム＆ゲームポータルWebサイトです。

🎮 **公開ページ (GitHub Pages)**: [https://fps262626.github.io/game-web-FPS/](https://fps262626.github.io/game-web-FPS/)

---

## 🌟 主な特徴

- ⚡ **超軽量 & 60FPS動作**: 外部の重量ライブラリを使わず、Pure HTML5 Canvas & Vanilla JavaScriptで超高速・快適動作
- 🎯 **ターゲットシューティングFPS内蔵**:
  - マウス・タッチ操作による精密エイミング＆射撃
  - ヘッドショット（クリティカル判定）＆コンボボーナスシステム
  - 反動（リコイルシェイク）、マズルフラッシュ、爆発パーティクル、弾痕トレーサー
  - 弾薬数（30発）＆リロード機能（RキーまたはUIクリック）
- 🔊 **Web Audio API シンセサウンド**:
  - 音声ファイルのダウンロード不要！ブラウザ内でリアルタイム周波数合成（銃声、金属着弾音、クリティカル音、リロード機構音）
- 📱 **レスポンシブ & フルスクリーン対応**: PC、タブレット、スマートフォン（タッチ操作）対応
- 🏆 **ハイスコア & 戦績保存**: ローカルストレージにスコア、命中率、最大コンボを保存
- 🎨 **サイバーネオン / タクティカルテーマ切替**: 右上のテーマボタンでカラーチェンジ可能

---

## 🕹️ 操作方法

| キー / 操作 | アクション |
| :--- | :--- |
| **マウス移動 / タッチ** | 照準（クロスヘア）のエイミング |
| **左クリック / タップ** | 射撃 (FIRE) |
| **[ R ] キー** / 弾薬UI | マガジンリロード (30発) |
| **[ P ] / [ ESC ] キー** | 一時停止 (PAUSE) |
| **[ F ] キー** / 画面右上アイコン | フルスクリーン切り替え |

---

## ⚙️ 独自ゲームへの差し替え・カスタマイズ

ご自身で作成したWebGL、Three.js、Unity WebGL、iframeゲームに差し替える場合は、`index.html` の `#game-container` 内を差し替えるだけで、サイバーフレームやHUDのレイアウトをそのまま活用できます。

```html
<div class="game-container" id="game-container">
  <!-- ここに独自のゲームCanvasやiframeを配置 -->
  <canvas id="my-custom-fps-game"></canvas>
</div>
```
