// OPERATIONAL CONTROLS 操作マニュアル

🖱️

マウス移動 / タップ

照準（クロスヘア）をターゲットに合わせます。直感的なエイミングが可能です。

左クリック

射撃 (FIRE)

標的を射撃します。中心に近いほど高得点（クリティカル）を獲得できます。

R

リロード (RELOAD)

マガジン（30発）を再装填します。弾切れ時または下部ゲージクリックでも実行可能です。

P / ESC

一時停止 (PAUSE)

ゲームを一時停止して作戦状況を確認できます。再度押すかクリックで再開します。

F / ⛶

全画面・画面拡大

ゲーム画面上部の「画面拡大」ボタンまたはキーボード[F]で画面全体に拡大。スマホでも大画面で迫力プレイが可能です。

連射制限

戦術的トリガー

無駄撃ちを避けて命中率を高く保つことで、最終リザルトの評価ランクが向上します。

⚙️

ゲームの追加・差し替えについて

このページは独自のゲーム（WebGL, Three.js, Canvas, iframe）をいつでも組み込める構成になっています

現在内蔵されている「CYBER TARGET FPS」のほか、ご自身で開発したFPSや3Dゲーム、外部ゲームを配置する場合は、 index.html の #game-container 要素内に Canvas や <iframe> を配置するだけで、 本ページのゲーミングHUD・フルスクリーン機能・サイバーフレームデザインをそのまま活用できます！

<!-- 独自ゲームの組み込み例 --> <div class="game-container" id="game-container"> <!-- ここにThree.jsのCanvasや、Unity WebGL、ゲームフレームを配置 --> <canvas id="my-custom-fps-game"></canvas> </div>
